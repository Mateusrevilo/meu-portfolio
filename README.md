# Portfólio - Mateus

Portfólio pessoal desenvolvido com **Next.js 16**, **React 19**, **TypeScript** e **Tailwind CSS**, apresentando projetos, habilidades e informações de contato.

## 🚀 Como rodar o projeto localmente

### Pré-requisitos

- **Node.js** 18.2 ou superior
- **npm**, **yarn**, **pnpm** ou **bun**

### Passo a passo

1. **Clone o repositório** (ou acesse a pasta do projeto):
   ```bash
   cd my-app
   ```

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Execute o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

4. **Abra no navegador**:
   ```
   http://localhost:3000
   ```

O projeto irá recarregar automaticamente ao editar os arquivos.

## 🌐 Deploy e versão online

### Deploy na Vercel (recomendado)

A forma mais fácil de fazer o deploy de um projeto Next.js é usando a [Vercel](https://vercel.com):

1. Acesse meu-portfólio-lac-ten.vercel.app
2. Conecte seu repositório GitHub/GitLab/Bitbucket
3. A Vercel detectará automaticamente as configurações do Next.js
4. Clique em **Deploy**

Para mais detalhes, consulte a [documentação oficial de deploy do Next.js](https://nextjs.org/docs/app/building-your-application/deploying).

### Versão online

Se o projeto já estiver publicado, acesse a URL da Vercel ou do serviço de hospedagem configurado.
